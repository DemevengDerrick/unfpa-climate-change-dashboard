# UNFPA Population Hazard Exposure Explorer

Interactive dashboard for the UNFPA Population Hazard Exposure Database (2025 baseline and SSP1–5 projections to 2100).

**Open it:** `index.html` is a single self-contained file (about 4.4 MB). It needs no server or internet connection. Open it in a current version of Chrome, Edge, Firefox or Safari.

## Tabs
- **Map**: choropleth with 5 measures (% exposed, people exposed, rural share, SSP change, ≥ N hazards) and zoom to each UNFPA region.
- **Compare groups**: UNFPA regions, World Bank income (FY26/FY27), demographic dividend phase, OECD fragility, LLDC/SIDS.
- **Profile**: any country, area, region or group.
- **Demographic groups**, **Urban & rural** (Degurba), **Futures (SSP)**, **Multi-hazard** (including 8-layer combinations).
- **Data & notes**: sortable table, CSV downloads, metadata, hazard taxonomy and the database README.

Group values are population-weighted: total people exposed divided by total population.
Maps use the Robinson projection and UN boundaries.

*The boundaries and names shown and the designations used on the maps do not imply official endorsement or acceptance by the United Nations.*
